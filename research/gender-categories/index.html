03 これは、ふつうなのか

「男」「女」と言った瞬間に、
こぼれ落ちるもの

QUESTION

「男は」「女は」と言うとき、私たちは何を説明していて、何を説明していないのか。

SUMMARY ／ 3行でわかる

  • 心理的な性差を統合すると、平均的な大きさは d = 0.21。106件のメタ分析をまとめた値である。
  • この大きさでは、二つの分布は約9割重なる。平均の差から、目の前の一人を推定することはできない。
  • ただし例外がある。性の領域は、心理学のなかでも差が大きく出る項目を含んでいる。ラベルが「当たっているように見える」のはそのためだ。

1. 通説と、その説明力

「男は◯◯だ」「女は△△だ」。この語り方は、驚くほど効率がよい。二語で、数千万人を仕分けられる。日常会話でも、恋愛相談でも、広告でも、これが使われない日はない。

本記事は、この語り方の是非を論じない。説明力——観察されるデータをどれだけ再現できるか——だけで評価する。

通説A「男と女は、まったく別の生き物だ」。この枠組みはメディアを長く占めてきた[1]。だが後で見るように、測られた心理変数のほとんどで、二つの分布はほぼ重なっている。説明力は低い。

通説B「性差など存在しない」。これも事実に反する。平均の差は、領域によっては確かに存在する。とくに性の領域にはそれが現れる[5]。

通説C「平均に差があるのだから、個人も推測してよい」。本記事が扱うのはここである。この一歩が成り立つかどうかは、信念の問題ではなく、分布の形で決まる。数字を見ていく。

2. 数字で見ると、どうなっているのか

2-1. 効果量という物差し

二つの集団の差を測る標準的な道具に、効果量 d（Cohen's d）がある。二群の平均の差を、ばらつき（標準偏差）で割った値だ。慣習的な目安として、0.2 で「小」、0.5 で「中」、0.8 で「大」とされる[8]。

言い換えれば d は、平均どうしが、ばらつき何個ぶん離れているかを表す。身長なら d はかなり大きい。問題は、心理的な指標でどうなるかである。

2-2. 統合すると、d = 0.21

Hyde（2005）は46件のメタ分析を集約し、男女は「ほとんどの、ただしすべてではない」心理変数で類似していると結論した[1]。これは論争を呼んだ。

10年後、Zell・Krizan・Teeter（2015）が、その後に蓄積された106件のメタ分析・386の効果量を再統合した。結果は次のとおりである[2]。

  • 男女の平均的な絶対差は d = 0.21（SD = 0.14）
  • 効果の 46% が「小」、39% が「非常に小」。合わせて85%
  • 領域（認知／社会・性格／well-being）で多少変動するが、年齢・文化・世代を通じてほぼ一定

2-3. 0.21 とは、どれくらいか

数字だけでは大きさがつかめない。描いてみる。

d = 0.21 のとき、二つの分布は約92%重なる。無作為に一人ずつ選んで比べたとき、平均の高い側が上回る確率は約56%。コイン投げが50%であることを思えば、ほとんど変わらない。

慣習的に「大きい」とされる d = 0.80 ですら、重なりは約69%、上回る確率は約71%である。「大きい差」でも、3割近くは逆転する。

2-4. 分類なのか、程度なのか

ここまでは「差の大きさ」の話だった。もうひとつ別の問いがある。そもそも男女は、二つのカテゴリなのか、それとも連続した程度なのか。

Carothers と Reis（2013）は、タクソメトリック分析という手法でこれを検証した。この手法は、ある構成概念の潜在構造が分類的（taxonic）か次元的（dimensional）かを判定する[3]。

  • 身体的特性（握力・身体計測）と、ステレオタイプ的な趣味 → 分類的
  • 心理的指標（性的態度と行動、配偶者選択、ソシオセクシュアリティ、共感性、関係的自己、男性性・女性性、Big Five、親密さ）→ わずかな例外を除き 次元的

論文の結論を、そのまま引く。

男女の平均差が争われているのではない。ジェンダーが次元的であることは、性別にもとづいて個人の心理的特性を判定することが不適切だ、ということを意味する。

2-5. 脳も、二つに分かれていない

「男性脳／女性脳」という言い方がある。Joel らは4つのデータセット、1,400超の脳MRIを分析した[4]。

結果は二点である。第一に、灰白質・白質・結合のすべてで、男女の分布は大きく重なっていた。第二に、「すべての特徴が男性側」「すべて女性側」という内的に一貫した脳は、まれだった。大半の脳は、男性に多い特徴・女性に多い特徴・どちらにも共通の特徴が混ざったモザイクである。

同じ分析を、5,500人超の性格・態度・関心・行動に対しても行っている。内的一貫性は「極めてまれ」だった[4]。つまり「男らしさ一式」「女らしさ一式」を揃えて持っている人は、ほとんどいない。

2-6. ただし、性の領域は例外である

ここが、本記事にとって最も重要な節である。

Petersen と Hyde（2010）は、30の性行動・性的態度について、834の個別サンプルと7つの大規模国家データを統合した[5]。

多くの差は、やはり小さかった。しかし例外がある。マスターベーション経験、ポルノ利用、カジュアルセックス、カジュアルセックスへの態度。これら4つは中程度の効果量を示した[5]。

つまり、性の領域は、心理学のなかでも差が大きく出やすい領域を含んでいる。「男はこうだ」というラベルが、この話題でとくに当たっているように感じられるのは、そのためだ。

だが同じ論文には、もうひとつ重要な所見がある。男女平等度が高い国や民族集団ほど、一部の性行動で差が小さかった[5]。発表年によって、拡大した差と縮小した差の両方があることも報告されている。

差は固定値ではない。条件によって動く。

3. NXYはこう読む

ここから先は解釈です。前節までの記述とは性質が異なります。

「男」「女」と言った瞬間にこぼれ落ちるものは、三つある。

ひとつめ。当てはまらない人は、例外ではない。
d = 0.21 で分布は約92%重なる。「男はこうだ」が当てはまらない男性は、少数の変わり者ではない。多数派に近い。ラベルは、その人たちを「例外」という箱に押し込むことで成立している。

ふたつめ。領域ごとの差の大きさが、消える。
「男は」という一語は、d がほぼゼロの領域と、中程度に達する領域を、まったく同じ強さで語ってしまう。一語に括った瞬間、どこが大きくてどこが小さいかという情報そのものが消える。本当に知りたいのはそこなのに。

みっつめ。程度が、分類にすり替わる。
Carothers と Reis が示したのは、心理的な指標の多くが連続量だということだった[3]。連続量を二つの箱に入れると、箱の中のばらつきが見えなくなる。そして実際には、箱の中のばらつきのほうが、箱と箱のあいだの差より大きい。

では、こぼれ落ちたあとに何が残るのか。

「もう理解した」という感覚だけが残る。

ラベルは、理解を節約する道具である。そして節約できた分だけ、確認しなくなる。相手に聞かなくなる。「男ってそういうものでしょう」「女の人はそうだよね」で、会話が閉じる。

やっかいなのは、NXY が扱う領域——惹かれあい、触れること、性——が、まさに差が大きく出やすい領域だという点である[5]。だからここでは、ラベルがいちばん当たっているように見える。それでも、中程度の差ですら分布は8割前後重なっている。当たっているように見えることと、目の前の一人に当たっていることは、別である。

NXY の記事も「男性は」「女性は」と書く。それは便宜である。平均の話をするときに、他に簡潔な書き方がないからだ。この記事は、そのための但し書きとして置いている。

4. この説明の限界と反証

「差はない」とは言っていない

平均差は存在する。領域によっては中程度の大きさになる[5]。本記事が述べたのは、平均差から個人を推定することはできないという一点だけである。これを「性差は存在しない」と読み替えないでいただきたい。

「小さい」の基準そのものが争われている

Zuriff（2015）は、類似性仮説に対してこう批判した。この仮説は、検討する次元の心理的な重要性を測る尺度も、次元をいくつと数えるかの規則も示していない。したがって、定式化されたままでは検証不可能である[6]。

これは本記事にもそのまま当てはまる。「386の効果量の平均が 0.21」という数字は、どの386を選んだかに依存している。

小さな効果が、大きな帰結を生む場面がある

選抜や評価が繰り返される場面では、一回あたりは小さな差でも累積する。d が小さいことは、社会的な影響が小さいことを意味しない。本記事は「個人の推定」について述べたのであって、制度設計について述べたのではない。

文化差について、報告が食い違っている

Zell らは、差の大きさが文化・世代を通じてほぼ一定だったと報告している[2]。一方 Petersen と Hyde は、男女平等度によって一部の差が変わると報告している[5]。対象とした領域が違うため直接の矛盾ではないが、統合された像はまだない。

参加者の偏り

ここで引いた研究の多くは、西洋・教育水準が高く・産業化され・裕福で・民主的な社会の参加者に偏っている[7]。日本のデータでこの数字がそのまま再現されるかどうかは、別に確かめる必要がある。

自己報告に依存している

性行動・性的態度の測定は、その多くが自己報告による。何を正直に答えやすいかは、性別によって方向が異なりうる。観察された差の一部が、報告の仕方の差である可能性は残る。

性別を二値で記録した研究である

本記事が引いた研究の大半は、性別を男女の二値で記録している。その枠に収まらない人は、そもそも測られていない。「二分法の限界」を二分法のデータで論じているという循環は、本記事の構造的な限界である。
